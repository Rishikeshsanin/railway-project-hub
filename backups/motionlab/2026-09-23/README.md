# MotionLab Pre-Retirement Backup

This directory preserves the non-secret Railway configuration needed to understand or restore MotionLab after retirement of its standalone Railway project.

Files:
- `RAILWAY_SNAPSHOT.json` — machine-readable pre-retirement infrastructure snapshot.
- `RESTORE.md` — human-readable restoration procedure.

No secret values are stored here.

The application source remains preserved in `Rishikeshsanin/animation-website`, including the archive branch `archive/pre-railway-retirement-2026-09-23`.
